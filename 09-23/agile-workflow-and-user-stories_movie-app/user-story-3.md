# Title

## Value Proposition

**As a** `User` <br>
**I want to** `add movies to a watchlist which is displayed on a new page` <br>
**so that** `I can store and acces my favourite movies faster` <br>

## Description

![wireframe](./assets/scribble-watchlist.png)

## Acceptance Criteria

- on the details page there is a button to add the respected movie to a watchlist page
- the watchlist consists of all bookmarked movies
- every movie in the watchlist shows an image, title and rating
- when no movie has been added, a message is shown to inform the user about the current status and call to action
- a navigation bar on the page bottom let the user switch between the Homepage and Watchlist page

## Tasks

- create a button inside the Details-Page
- create a navbar with links to the homepage and Watchlist-page
- create a Watchlist-page-file
- render the Card-Component inside the Watchlist-page
- if no movies are added, display a message-text
