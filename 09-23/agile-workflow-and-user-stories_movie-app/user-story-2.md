# Movies Details Page

## Value Proposition

**As a** `User` <br>
**I want to** `see the details of each movie` <br>
**so that** `I can get further information about the movie` <br>

## Description

![wireframe](./assets/scribble-movie-details-page.png)

## Acceptance Criteria

- when clicking a movies image on the homepage, a details page opens
- the details page consists of the movie title, the release date, an image and a description of the movies content
- the user is able to go back to the homepage via a button/back arrow

## Tasks

- create a feature-branch
- create dynamic route file [slug]
- find data: title, release date, image and description via dynamic routes
- implement click handler to open the respective details-page
- create backbutton-component
